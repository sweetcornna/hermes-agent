## 修复与验证

共享绑定函数只对OneBot群会话解码标准的`g`加数字形式，且要求对应纯数字配置项明确设置`group: true`。继续拒绝私聊冒用前缀、`group:`等手输别名、其他平台、未绑定群和其他人格；不做宽泛别名扩展。原有纯数字调用仍兼容。

这一个插件内修复同时覆盖身份、状态、生活工具和压缩策略的调用路径。没有改核心代码、人格内容、模型参数或QQ客户端。动态状态仍附在当前用户消息，既有冻结前缀不被改写。

- [工程回归](tests.txt)：278项通过、0失败，包含原270项与8项新增实际群号/拒绝边界验证。
- [生产快照预演](preflight.txt)：使用私有插件副本、真实AIAgent与当前5群/1私聊元数据，6个绑定都获得完整人格、生活状态、工具和压缩策略；额外检查其他平台不注入。
- 人格哈希仍为`279adcee99ca5e2f3010ad3503239e71bc98f6ac925022af4d46b4a66df1ae68`，此前通过的表达对照样本继续对应当前内容；本轮没有重采或更改表达评分。
