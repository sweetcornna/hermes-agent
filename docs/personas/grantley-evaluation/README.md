# 格兰人格校准：对话与工程验证

最新一轮使用现用`gpt-6-astra`、192条最终回复与独立的新留出场景，见[2026-09-07人格与自然表达验收](../grantley-humanizer-20260907/README.md)。以下保留此前模型与人格版本的历史结果。

二代档案、室友分支、教师身份、异译、群主关系和现实执行边界均已落实。最终一轮 24 组对照中，按预设案例要求 **22 项通过、2 项部分通过**。第13、22项没有编造剧情，但仍出现对“没有可靠记录”的范围说得过满；不把它们记成完全通过，也不宣称人格提示能杜绝幻觉。

## 方法与限制

- 模型：用户现有 Hermes 配置中的 `cornna / gemini-3.7-flash-tiered`。两侧实际返回模型名相同。
- 所有采样统一 `temperature=0.4`、`max_tokens=1200`，每个版本每案例一次，独立新对话，无工具和真实聊天历史。
- 使用修改前工作树人格与修改后人格，连同各自真实的频道渲染结果。合成 owner/friend 身份和固定日常状态相同；比较的是完整人格修改效果，包含取消旧频道里的日程注入。
- 这是隔离 API 对话采样，不是向 QQ 发消息，也不是完整生产工具调用 E2E。专业代码另外执行验证；工具权限、会话恢复与状态注入由本地真实导入测试覆盖。
- 评分由实施的 Codex 主任务读完原始输出后给出，四维各0–2分：事实准确、语气贴合、自然程度、任务完整。不是独立盲评、统计显著性结论或长期稳定率。
- 本组案例同时用于迭代与验收，属于开发集，不是未见过的独立测试集。随机采样会波动；不能把22/24推广成所有对话的准确率。

## 分项评审

[逐项四维评分与理由](review.json)及[完整并排对照](comparison.md)覆盖全部24个案例。几个显著变化：

- 弗罗汀从旧版的“城”改为国家；戴德里克与西利欧从杜撰的学长身份改为教官和校长。
- 不再把“原室友”说成谣言，能解释二代重新选择室友。
- 不再杜撰具体声优、家业、穿墙限制或与他人碰面时的细节。
- 不把群主身份自动理解为暗恋，也不将原创吃饭日常说成原作章节。
- 复杂任务仍保留代码、格式和边界示例，不因普通群友身份而敷衍。

仍需关注：第12项说明偏长，第17项拒绝强行恋爱设定时较冲；第13、22项在缺证据时偶尔漏掉“我目前查到的”限定。稳定提示已给出正确规则，但这轮输出表明模型执行仍有余量。没有新增输出关键词拦截器去掩盖问题。

## 工程验证

运行仓库要求的 `scripts/run_tests.sh`，7个相关文件 **197项通过、0失败**，详见[原始测试输出](tests.txt)。覆盖：

- 真实插件注册与系统提示构建，身份只注入一次，未绑定的频道和其他平台不注入。
- 真实 SQLite 保存与恢复：资源升级后，旧会话保留原身份，新会话采用新身份。
- 当前状态经 MemoryProvider 与消息组合路径附到当前用户消息，稳定前缀不随情绪变化。
- 频道文案对日期、生活活动和种子变化保持字节一致，群聊、私聊、主动与被动路径一致。
- 所有抽样类别都有本地种子；抽样落在各自池中，教师不混入同届伙伴；已有覆盖规则保留。
- 稳定人格3072字符，低于4000字符上限。整文件哈希与固定措辞测试已改为加载、传递、抽样及会话恢复契约；真正的缓存字节比较保留。

[生成代码执行检查](code-check.json)核验最后一轮两个二分查找函数，在有序数组、空数组、重复元素与缺失目标上与标准库 `bisect_left` 结果一致。它验证这两个样本的代码，不代表其他编程任务均正确。
