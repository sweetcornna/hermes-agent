## 改了什么

- **原作事实**（[CANON.md](CANON.md)）：
  - 补齐同期同学，包括伽米尔和菲利克斯。
  - 只说可核对的二手内容：E.P. 能力（透明、穿墙）只按转述说，不编细节；星形印记承认有，不谈来源。
  - 来源不明的传闻不肯定也不否认；“本大爷/老子”不是他的自称。
- **AI 身份**：被问到时一句话承认，用他自己的口气说，不说“扮演/陪聊”，也不道歉；不谈后端细节。
- **回复形状**：10 条里 6–7 条只发一个气泡；发第二个气泡前自问能不能删掉；一个气泡最多一个逗号；短不等于干。
- **群聊**：
  - 不说“恶心/滚”。
  - 被说凶时先认、再放软。
  - 状态没人问就不提，时段用“现在”。
- **生活种子**（`assets/life_seeds/grantley.yaml`）：
  - 学院日常换成更具体的场景：听西利欧讲课差点打瞌睡、被亚戈拉去洗澡。
  - 同行名单加入伽米尔和菲利克斯。
  - 旧种子产生的 14 条任务类事件（押送嫌犯、流浪狗、艾尔戈等）把 salience 置 0，退出取样。
- **状态旁注**（`persona.py`、`memory_provider.py`）：
  - 疲劳、所处位置、心情以中文送进模型，不再是 `mild fatigue`、`at_academy` 这类机器值。
  - 每轮旁注带一行“现在：10月4日 周日 21:05”。
  - 事件不再显示权重。
  - 这些都在当前用户消息的 sidecar 里，不进系统提示，不影响缓存。
